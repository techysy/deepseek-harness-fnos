## 🚀 DeepSeek Harness fnOS 0.2.2-rc.1.1

上游 `@deepseek-ai/dsh` 保持 **v0.2.2-rc.1** 不变，本版为管理面板热修复（构建段 1）。核心新增：**本地上传 fpk 一键安装**。

### 🛠 新增：上传 fpk 安装（NAS 拉不到 GitHub 也能升级）

此前面板只有「一键下载到 NAS」一条路径，依赖 NAS 自身能访问 GitHub。实测常遇到：

- NAS 到 `github.com` 建连超时（半死连接）；
- 未配置出站代理，或代理不可用；
- 下载报「操作失败」，用户无从下手。

本版新增 **「上传 fpk 安装」**：

1. 在电脑上打开 [GitHub Release](https://github.com/techysy/DeepSeek-Harness-fnos/releases) 下载对应架构的 `.fpk`；
2. 面板 → 版本 / 更新 → 点「上传 fpk 安装」，选择该文件；
3. 上传完成后文件自动出现在「已下载的更新」列表；
4. 点「标准安装 (appcenter-cli)」或「强制覆盖热安装」完成升级。

全程走浏览器 → NAS 局域网传输，**NAS 无需访问 GitHub**。

### 🔒 上传安全与健壮性

| 项目 | 处理方式 |
|---|---|
| 大文件 | 流式写入 `.uploading` 临时文件，~180MB 的 fpk 不整包进内存 |
| 文件类型 | 仅接受 `.fpk` 后缀 + zip 魔数校验（防止改名伪装） |
| 路径安全 | 文件名 `basename` 化，拒绝 `../` 穿越 |
| 大小上限 | 600 MB |
| 卡住检测 | 60 秒无数据自动中止（与下载侧看门狗同一思路） |
| 中断清理 | 失败/中断自动删除 `.uploading` 半成品，不留垃圾 |
| 提前拒绝 | 超限/类型错误时先排空请求体再回包，浏览器看到友好提示而非「传输中断」 |

### ✨ 其他改进

- **多文件逐个安装**：update 目录有多个 fpk 时，每行出现「装这个」按钮，可精确选择要安装的版本（此前只能装排序最后一个）。安装接口新增可选 `name` 参数，服务端会校验该文件必须真实存在于目录列表中。
- **修复文案裸露**：截图中出现的 `sudoAlready` 等原始 key 是 i18n 缺失导致 —— 共 **9 个 key**（`sudoFoot`、`sudoRecheck`、`sudoPartial`、`sudoAlready`、`cmdInstall`、`cmdHot`、`sudoPartialTip`、`applyNeedInstall`、`applyNeedHot`）在中英文包里都未定义，已全部补齐。现中英各 146 条文案，完全对齐。
- **下载失败引导**：失败提示下方新增说明，直接告诉用户「可改用上传或配置出站代理」。
- **安装错误透出**：标准安装失败时显示服务端具体原因，不再只有一句「安装失败」。

### ⚠️ 升级注意

- **从 0.2.2-rc.1 升级**：直接安装本版即可（版本号更大会被 fnOS 正常识别）。若已装 0.2.2-rc.1 且 App Center 提示版本相同时，可用面板「强制覆盖热安装」。
- **从更早版本升级**：先经面板更新到 0.2.2 系列，注意上游 0.2.2 的不兼容变更（Node ≥ 24.9、插件接口迁移，详见 v0.2.2-rc.1 说明）。
- **数据保留**：会话、API Key、代理配置、信任域名均完整保留。
