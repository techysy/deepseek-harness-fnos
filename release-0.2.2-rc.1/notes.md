## 🚀 DeepSeek Harness fnOS 0.2.2-rc.1

基于上游 [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) **v0.2.2-rc.1** 构建（0.2.2 系列首个 RC，大版本）；含管理面板更新下载修复 (#11)。

### 🛠 新增：上传 fpk 安装（NAS 拉不到 GitHub 也能升级）

此前只有「一键下载到 NAS」一条路径，依赖 NAS 自身能访问 GitHub；实测常遇到建连超时（半死连接）或未配置出站代理，下载直接失败。本版新增**上传入口（按钮行首位、主按钮）**：

1. 电脑上打开本项目 Release 下载对应架构的 `.fpk`；
2. 面板 → 版本 / 更新 → 点「上传 fpk 安装」，选择该文件；
3. 上传完成后自动出现在「已下载的更新」列表；
4. 点「标准安装」或「强制覆盖热安装」完成升级。

全程走浏览器 → NAS 局域网传输，**NAS 无需访问 GitHub**。

| 安全 / 健壮性 | 处理方式 |
|---|---|
| 大文件 | 流式写入 `.uploading` 临时文件，~180MB 的 fpk 不整包进内存 |
| 文件类型 | 仅 `.fpk` 后缀 + zip 魔数校验（防止改名伪装） |
| 路径安全 | 文件名 `basename` 化，拒绝 `../` 穿越 |
| 大小上限 | 600 MB |
| 卡住检测 | 60 秒无数据自动中止（与下载侧看门狗同一思路） |
| 中断清理 | 失败/中断自动删除 `.uploading` 半成品 |
| 提前拒绝 | 超限/类型错误时先排空请求体再回包，浏览器看到友好提示而非「传输中断」 |

其他改进：**多文件逐个安装**（目录内有多个 fpk 时每行出现「装这个」，可精确选择；服务端校验文件名必须在列表内）；**修复 9 个缺失的 i18n 文案**（其中 `sudoAlready` 曾在界面裸露为原始 key）；**下载失败引导**（提示可改用上传或配置代理）；**安装失败透出真实原因**。

### 🐛 修复：fpk 上传魔数校验（支持 gzip / tar.gz 与 zip 容器）

- 修复因魔数仅识别 zip 导致真实的 fnOS fpk (gzip 归档) 上传被误拒的问题，现完整支持 gzip 与 zip 两种合法归档；
### 🐛 关键修复：解决面板前端脚本语法错误（界面停留 ... 骨架问题）

- 修复因模板字符串嵌套单引号和换行符导致的浏览器端 `SyntaxError`，确保前端国际化、图标与全部功能脚本正常执行加载；
### 🎨 插件卡片布局优化 (#13)

- **插件名完整显示**：名称独占首行、可伸缩省略，并保留悬浮 `title`；此前长名称被截断成 `@deepseek-ai/dsh-experimen...`；
- **操作区对齐**：状态胶囊、官方/第三方徽章、启用/禁用、删除按钮统一移到第二行右对齐，高度统一 22px，不再高低错落或换行挤压；
- **版本缺失更明确**：插件登记在 bundles 但未实际安装时，版本位显示「未安装」而非裸 `?`。
### 🔄 新增：重启面板（热安装后立即加载新代码）

**此前的问题**：热安装只重启 dsh 与网关代理，面板进程被刻意保留——结果面板一直跑着覆盖前的旧 `cmd/dashboard.js`，新功能（比如上传入口）根本看不到，只能重启整个应用。

**现在**：

- **热安装后自动重启面板**：`hot-apply` 成功后自动重载面板进程，装完刷新页面即见新版本；
- **工具栏新增「重启面板」按钮**：随时手动重载，用于覆盖文件后加载新代码；
- **可靠的重启实现**：优雅终止旧进程 → 等待端口真正释放 → 拉起新进程 → 校验新 pid 存活；面板自己写 `dashboard.pid`（不覆盖存活进程的记录），旧进程主动让出端口避免竞争。

### ✨ 上游主要特性（0.2.1-rc.5 → 0.2.2-rc.1）

- **移动端全面适配**：软键盘交互、导航与窄屏布局优化，菜单与操作入口在手机上保持可用。
- **工作台交互增强**：
  - 统一右键与键盘菜单，覆盖会话、工作区与侧边栏，并支持开发者扩展；
  - 文件预览支持常驻目录树与文件定位；
  - 支持将聊天文本作为引用插入输入框；完整历史会话可复制为 Markdown；
  - 工作步骤收起后保留全部助手文字回复，可切换「仅最终回答」。
- **多语言界面**：新增日语、西班牙语、法语、德语、俄语、巴西葡萄牙语文案与界面配置。
- **插件管理增强**：插件详情支持富文本展示；支持更新第三方插件包，热更新失败时自动回退旧版本。
- **新增实验性能力**：`subagent_oar`（把独立任务交给本机 Codex/Claude CLI）、个性化推荐、开发者工具-统计、变更请求与工作树（独立 Git 工作树 + 逐文件差异与 PR 状态查看）。
- **新工具**：默认关闭的 `apply_patch`，一次完成多文件新增、编辑、删除和移动。
- **问题修复**：AGENTS.md 预算隔离、子代理/会话分支识别、历史会话无法打开、Web Fetch 编码、Markdown 与 Math 渲染、Trajectory 工具输出展示等大量修复。

### ⚠️ 不兼容变更（升级前请阅读）

- **Node.js 最低版本提高至 24.9**：上游 `package.json` 新增 `engines: node >=24.9.0`。本包已在 CI（Node 24）完成构建与补丁验证；若 NAS 上 `node -v` 低于 24.9，请先在应用中心升级 `nodejs_v24` 依赖应用。
- **PTC 架构调整**：原生与 PTC 工具执行拆分为按 Agent 作用域选择的插件，PTC 改由配置 overlay 启用；旧 `tools.mode` 与 `DSH_TOOLS_MODE` 需迁移。SSH helper 协议由 2 升至 3。
- **自定义插件需迁移**：异步会话投影句柄、`tools.resolve/executable`、提示词组装接口均有变更。
- **「Git 工作树」入口合并**：此前启用过独立插件的用户，需手动从 profile 的 `dsh.profile.bundles` 移除 `@deepseek-ai/dsh-experimental-tool-worktree`。
