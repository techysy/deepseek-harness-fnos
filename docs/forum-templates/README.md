# fnOS 论坛发帖模板

本目录包含在飞牛论坛发布 DeepSeek Harness 应用的发帖模板。

## 可用模板

### 1. `fnos-forum-final.md`
**完整版本**，包含所有详细信息：
- 应用预览区
- 完整功能说明
- 详细的亮点列表
- 数据保护说明
- 安全提醒
- 交流群链接

适合：首次发布、重点推介、功能更新时使用。

### 2. `fnos-forum.md`
**标准版本**，内容均衡：
- 核心功能说明
- 主要亮点
- 安装步骤
- 配置指南
- 基本安全提醒

适合：常规更新、应用中心上架时使用。

### 3. `fnos-forum-simple.md`
**简洁版本**，快速介绍：
- 项目简介
- 核心优势（表格形式）
- 快速安装步骤
- 基本使用说明
- 关键注意事项

适合：社区讨论、快速转发、提示性发帖时使用。

---

## 使用说明

1. 根据需要选择对应的模板
2. 替换以下占位符：
   - `[在这里插入应用界面预览图 / 截图]` → 实际的应用截图
   - `[在这里插入飞书群二维码 / 群链接]` → 实际的交流群链接
3. 调整版本号和链接（如有新版本发布）
4. 复制内容到飞牛论坛发帖

## 如何更新模板

当新版本发布时：
1. 更新版本号（例如 `0.1.0-rc.7` → `0.1.0-rc.7`）
2. 更新相关链接和功能说明
3. 保持模板结构不变
